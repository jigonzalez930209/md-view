# Shortcuts

## Application

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ + O` | Open file |
| `Ctrl/⌘ + N` / `Ctrl/⌘ + T` | New tab |
| `Ctrl/⌘ + W` | Close tab |
| `Ctrl/⌘ + Tab` | Next tab (`Shift` for the previous one) |
| `Ctrl/⌘ + Shift + E` | Show/hide the folder explorer |
| `Ctrl/⌘ + ,` | Settings |
| `Ctrl/⌘ + S` | Save (asks for a path the first time) |
| `Ctrl/⌘ + Shift + S` | Save as |
| `Ctrl/⌘ + 1` / `2` / `3` | Editor only / split / read-only |
| `Ctrl/⌘ + F` | Search in the editor (the panel includes replace) |
| `Ctrl/⌘ + Alt + G` | Go to line |

## Formatting

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ + B` | Bold |
| `Ctrl/⌘ + I` | Italic |
| `Ctrl/⌘ + E` | Inline code |
| `Ctrl/⌘ + K` | Insert link |

The [formatting bar](/guide/formatting) does the same for headings, quotes, lists, task
lists, images, tables and horizontal rules.

## Editor (CodeMirror)

| Shortcut | Action |
| --- | --- |
| `Ctrl/⌘ + Z` / `Ctrl/⌘ + Shift + Z` | Undo / redo |
| `Ctrl/⌘ + D` | Select the next occurrence |
| `Alt + click` | Add a cursor |
| `Ctrl/⌘ + /` | Toggle line comment (in fenced code) |
| `Ctrl/⌘ + [` / `]` | Fold / unfold the section |
| `Tab` / `Shift + Tab` | Indent / outdent |
| `Ctrl/⌘ + Home/End` | Start / end of document |
| `Alt + ↑/↓` | Move the line up/down |

## Mouse

| Gesture | Action |
| --- | --- |
| Middle click on a tab | Close it |
| Double click on the title bar | Maximize / restore |
| Drag the window from the title bar | Move the window |
| Drag the separator next to the explorer | Resize the panel |
| Drag a `.md` onto the window | Open it |
