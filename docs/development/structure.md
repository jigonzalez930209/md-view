# Project structure

```
src/
  App.tsx                     Workspace state: tabs, layout, shortcuts, exports, appearance
  main.tsx                    Entry point; applies the theme before the first render
  components/
    HeaderBar.tsx             Title bar: Open, new tab, title, info, menu, window controls
    TabBar.tsx                Tab strip (shadcn Tabs, Chrome-like styling)
    FormatBar.tsx             Markdown formatting buttons
    Editor.tsx                CodeMirror host; one instance per tab
    Preview.tsx               Preview pane: Markdown/code toggle, windowing, notes
    FileTree.tsx              Folder explorer
    SettingsDialog.tsx        All preferences in one dialog
    StatusBar.tsx             Path, save state, cursor, word and character counts
    Welcome.tsx               Welcome screen with recents
    WindowResizeHandles.tsx   Invisible resize edges for the frameless window
    ui/                       shadcn components (button, dialog, dropdown, popover, …)
  editor/
    setup.ts                  CodeMirror extensions, themes and settings compartments
    format.ts                 Markdown commands (bold, lists, tables…)
  lib/
    backend.ts                Tauri bridge (with browser fallbacks)
    markdown-core.ts          markdown-it + plugins + KaTeX + highlighting (DOM-free)
    markdown.ts               HTML cache + DOMPurify sanitization
    mdx.ts                    MDX preprocessing
    enhance.ts                Preview post-processing: anchors, alerts, images, Mermaid, copy
    mermaid.ts                Lazy Mermaid loader, palette-aware theme
    highlight.ts              highlight.js wrapper
    scroll-sync.ts            Line-based scroll synchronization
    export.ts                 Export to PDF/HTML/PNG/JPG/WebP/SVG/TXT
    limits.ts                 Performance thresholds
    text-tasks.ts             Worker dispatcher (counts, Markdown render)
    prefs.ts                  Persisted preferences
    i18n.ts / i18n-react.tsx  Dictionaries, `t()`, provider and `useI18n()`
    theme.ts                  Theme and palette types, `applyAppearance`
    paths.ts                  Cross-platform path helpers
    utils.ts                  `cn()` (clsx + tailwind-merge)
    view.ts                   View modes and their translation keys
  workers/
    text-tasks.ts             Worker: statistics and Markdown rendering
  styles/
    index.css                 Tailwind entry, base layer, print rules
    theme.css                 Palettes (3 × light/dark) and tokens
    markdown.css              GitHub-style preview styles
  demo.md                     The document shown by "View demo"
src-tauri/
  src/lib.rs                  Commands: files, folder tree, recents, printing, links
  src/main.rs                 Binary entry point
  tauri.conf.json             Window, CSP, asset protocol, file associations
  capabilities/default.json   Window permissions
  icons/                      App icons (PNG, ICO, ICNS)
docs/                         This documentation site (VitePress)
scripts/
  generate-icons.py           Draws the app icon and exports every size
  release.sh                  Version bump + tag + push
.github/
  workflows/ci.yml            Typecheck, build, fmt and tests
  workflows/release.yml       Installers per platform
  workflows/docs.yml          Build and deploy this documentation
  RELEASING.md                Quick release reference
```

## Conventions worth knowing

- **`@/` alias**: `@/lib/...`, `@/components/...` map to `src/` (configured in `vite.config.ts`
  and `tsconfig.json`).
- **UI**: Tailwind v4 (CSS-first, no `tailwind.config.js`) plus shadcn components copied into
  `components/ui`. Icons come from `lucide-react`.
- **Preview CSS** is a separate stylesheet (`styles/markdown.css`) because the Markdown HTML is
  generated by markdown-it, not by React; it consumes the same CSS variables as the UI.
- **Comments** in the codebase are written in Spanish; identifiers, file names and all
  user-facing text are in English.
