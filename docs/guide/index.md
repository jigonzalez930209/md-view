# Guide

md-view is a desktop Markdown viewer and editor. It reads a `.md` file (or a whole folder),
renders it the way GitHub does, lets you edit it with a formatting bar and a CodeMirror
editor, and exports the result to several formats.

## The 30-second tour

1. **Open** a file from the welcome screen, or drag a `.md` onto the window, or use
   **Open folder…** to load a directory tree.
2. **Edit** in the left pane; the preview follows. The formatting bar above the editor
   inserts Markdown for you.
3. **Save** with `Ctrl/⌘ + S`. New documents ask for a path the first time.
4. **Export** from the main menu: PDF, self-contained HTML, PNG pages, JPG/WebP, vector SVG
   or plain text.

Everything is local: no account, no telemetry, no network calls except the links you decide
to open.
